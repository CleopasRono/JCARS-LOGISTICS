# JCARS-LOGISTICS
Power BI data analytics project transforming a raw Kenyan vehicle dealership dataset into a validated star-schema model, interactive dashboards, and actionable business insights.
## Project Objective
JCars Logistics imports, sells, and delivers vehicles to customers across Kenya. This project transforms a raw and uncleaned vehicle sales dataset into a reliable, interactive Power BI Business Intelligence solution designed to support management decision-making.
The solution provides insights into:

 -: Sales performance.
 -: Revenue and profitability.
 -: Branch and geographic performance.
 -: Vehicle and sales representative performance.
 -: Customer value.
 -: Logistics and delivery efficiency.
 -: Returns and payment activity.
 -: Data quality exceptions requiring further investigation.
The project covers the complete analytics workflow, from data cleaning and validation to data modeling, DAX development, visualization, and business insight generation.
